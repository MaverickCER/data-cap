Every data-flow projection now carries the evidence disclaimer inside itself: a leading comment in DOT and Mermaid, a blockquote in the Markdown view, the `dc:disclaimer` attribute on the PROV tool agent, a `data_cap.disclaimer` resource attribute in OTLP, a `data-cap:disclaimer` metadata property in CycloneDX and `metadata.remarks` in OSCAL. A test holds the sentence to the one the generated documents open with and fails if any adapter's own words claim compliance.

`buildOscalAssessmentResults` gains `evidenceHref` (every evidence reference becomes a back-matter resource with an `rlink` to the evidence file, and each observation's `relevant-evidence` points at it) and `strict` (refuses to build without a real `assessmentPlan` and `evidenceHref`); without a plan the placeholder `import-ap` now says so in `remarks`; a blank plan or href counts as absent. Finding targets changed: a control id (`ac-4`) is now targeted at its assessment objective (`target-id` `ac-4_obj`, `type` `objective-id`), a part id you give (`ac-4_smt.a`) is targeted as given, and `reviewed-controls` folds part ids back to their control; `metadata.remarks` is always present. A consumer keyed on the old `target-id` values must update.

Gates widened: the `./evidence` (32 KB) and `./node` (1 KB) entries carry gzip budgets; the ambient-capability tarball scan also rejects `process.env` outside the CLI; the `node:fs` import ban in `src/` is live again (two flat-config blocks had let the later one replace it); the observe isolation test also forbids side-effect and dynamic imports and the listed I/O globals; helpers, cache, retry, evidence and observe are executed under Bun and Deno in CI; a `required` CI check stands for every job the ruleset could not name, and `contract` fails instead of skipping when `verify` or `lint` fails; `npm run setup` installs the shared git hooks.

Documentation matches the tests behind it: the never-silently-safe catalog is 343 rows and the test asserts exactly that; the scale budget is stated as the 30-second gate; coverage is described as fixed floors raised in review; the compiler is described as bundled, about 24 MB; the data-flow surface is named as Experimental; the runtime matrix says which entries are executed on Bun and Deno; stale Node 18, dependabot and PERFORMANCE table entries are corrected.

TypeScript 7 consumers no longer need `skipLibCheck`: the build emits a second declaration tree (`dist/.dts7`) whose compiler-API types come from the bundled TypeScript 6, served only to TypeScript 7 through `types@>=7` export conditions; TypeScript 5 and 6 keep the declarations typed from their own `typescript`. The compat job type-checks every entry point but `./eslint-plugin` (typed through its `@typescript-eslint/utils` peer) with full library checking under all three, asserts which declaration set answered, and runs the flow pass over the flow-explorer example under each root, requiring byte-identical evidence.
